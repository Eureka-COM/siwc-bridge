# 設計方針

DSH（DeepSeek Harness）の既存Agent Loopとローカルツールはそのまま使い、モデル呼び出しだけを公式SIWCの公開Responses APIへつなぐアダプターです。

## 決定事項

- 公式プロトコルを独立実装します。SIWC DevKitの公開APIはツール入出力を扱えないため、DevKitのコードは含めません。
- DSH本体は改変しません。APIキー経路、別アカウントへの自動切替、別課金先へのfallbackは追加しません。
- 資格情報はWindows CurrentUser DPAPIとowner ACLで保護し、平文へ切り替えません。トークン更新はプロセスをまたぐ排他ロックの中だけで行います。
- 読み取りだけの処理はロックと復号を省き、暗号化ファイルが変わったときだけ読み直します（2026-10-11）。
- モデル一覧は表示用の情報として扱い、推論前に取り直しません。保存済みの一覧をすぐ表示し、裏で最新化します（2026-10-11）。
- 速度の指定（`service_tier`）は送りません。SIWCにFastを指定する公式の方法がないためです（2026-10-11）。
- 通常のテストは架空の資格情報と合成SSEだけを使い、実モデルを呼びません。

## 注意点

- PowerShellで `npm.ps1` が署名制限により動かない環境では `npm.cmd` を使います。実行ポリシーは変更しません。
- DSHのread-only設定は読取範囲のOS隔離を保証しません。ライブ検証では既存のtool guardでダミーファイル1個のreadだけを許可します。
